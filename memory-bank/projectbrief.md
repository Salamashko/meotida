# Project Brief — meotida
«Заявка в IT отдел» (v0.29, обновлено 03.06.2026) — автономное HTML-приложение для сотрудников ГК Миллениум: помогает оформить и отправить заявку в IT-отдел
(город, организация, программа, тип проблемы → готовое письмо с корректной темой и текстом) и подбирает инструкции из корпоративной Wiki (539 записей) по описанию проблемы.
Раздел для IT-администраторов содержит встроенные Python-скрипты обновления Wiki. Более новые версии живут в `meotida_2`.
